# KlaseKo interface

The shared design uses deep ink, mineral teal, neutral surfaces and reserved warm accents. Lexend's bundled font weights support clear hierarchy. Buttons have at least 48-pixel touch targets; primary actions use filled buttons, secondary actions use outlines, and navigation uses arrows with labels.

The four main destinations keep their state when switching. Phones use a labeled bottom navigation bar; screens at least 840 pixels wide use a navigation rail. System Back returns to Today from another main tab.

Onboarding has three named steps, persistent Back/Continue actions, required-field validation and optional practice data. It preserves profile values when going back. Class search and advisory filtering narrow the list without changing records.

Teaching workspace uses five scrollable labeled tabs: Policy, Assessments, Outcomes, Support and Reports. Each tab scrolls independently. Bounded form choices use dropdowns. Grade-period controls scroll horizontally when needed; class action grids adapt to narrow screens and larger text.

Light and dark themes share the same interaction hierarchy. Status labels include words rather than relying on color. Shared loading failures offer a retry action. Widget checks cover onboarding navigation/validation and narrow layouts with enlarged text.
